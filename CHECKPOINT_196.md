# Checkpoint 196 — Change of Basis: One Object, Many Descriptions

This is the synthesis lesson for the Change of Basis sequence.

## Numerical spine

- `B={(1,1),(1,-1)}`
- `C={(1,1),(2,0)}`
- `v=(3,1)`
- `[v]_B=(2,1)` and `[v]_C=(1,1)`
- `Q_(C<-B)=[[1,-1],[0,1]]`
- `[T]_B=[[2,1],[0,3]]`
- `[T]_C=[[2,0],[0,3]]`

## Story

1. A geometric vector stays fixed while its coordinate grid and coordinate column change.
2. Coordinate conversion is a map between descriptions.
3. Transition-matrix columns come from linear-combination recipes.
4. The same transition matrix converts every coordinate column.
5. Similarity changes the matrix description of a fixed transformation.
6. A good basis exposes simple structure.
7. A final checklist distinguishes changing vector coordinates from changing a transformation matrix.
