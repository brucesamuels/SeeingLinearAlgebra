# Checkpoint 83 — Which Transformations Are Linear?

CP83 turns the visual survey from CP82 into the precise definition of linearity.

Sequence:
1. Translation fails `T(0)=0`.
2. An origin-fixing nonlinear map shows that the origin test is not sufficient.
3. A shear passes `T(cv)=cT(v)`.
4. The shear passes `T(u+v)=T(u)+T(v)`.
5. The lesson concludes that linear transformations preserve linear combinations.

The renderer-independent engine computes both sides of each test; the Manim scene owns presentation and timing.
