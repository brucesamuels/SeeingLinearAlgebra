# Checkpoint 87 — Matrix Multiplication as Composition

\[
\mathbf{x}\xrightarrow{B}B\mathbf{x}
\xrightarrow{A}A(B\mathbf{x})=(AB)\mathbf{x}.
\]

The lesson applies \(B\), then \(A\), retains the endpoint, and replays the
same action using \(AB\). It ends by emphasizing that \(B\) acts first,
\(A\) acts second, and that \(AB\) generally differs from \(BA\).
