# Seeing Mathematics: Design Philosophy

Seeing Mathematics is a visual curriculum, not a collection of decorative videos.

1. Geometry comes before algebra.
2. Motion must reveal mathematical structure.
3. Linear combinations are built from scalar multiplication and addition.
4. Dimension loss should be visible as space collapsing to a plane, line, or point.
5. Every theorem answers a question already posed.
6. Colors, labels, and camera conventions remain stable.
7. Narration is conversational and mathematically precise.
8. Episodes include pause-and-predict moments.
9. Mathematical fidelity outranks spectacle.
10. The codebase is readable enough for student contribution.

## Litmus test

> What mathematical idea becomes easier to understand because this object moves?

If the answer is unclear, redesign or remove the animation.
