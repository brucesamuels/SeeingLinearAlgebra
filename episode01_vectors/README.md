# Episode 1 — Vectors

This version follows the progression of Mr. Samuels' lesson:

1. Three perspectives on vectors
2. Equivalent vectors by magnitude and direction
3. Scalar multiplication
4. Vector addition
5. Magnitude and Euclidean norm
6. Unit vectors
7. Standard basis and coordinates
8. Linear combinations as scalar multiplication followed by addition
9. Span in R, R^2, R^3, and R^n
